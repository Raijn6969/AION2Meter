# AION 2 Meter

Damage-Meter-Overlay für **AION 2** (Windows), im Stil von Questlogs Overlay.

**Download:** [neueste Version](https://github.com/Raijn6969/AION2Meter/releases/latest) → `AION2Meter.exe`

## Was du brauchst
- Windows 10 oder 11
- [Npcap](https://npcap.com) (kostenlos, Standard-Optionen)

## Was es kann
- DPS, Schaden, Anteil und Crit pro Spieler; Klick auf einen Spieler zeigt seine Skills
- Ziel-Filter: alle Ziele, nur Bosse, mein Ziel; Bossname in der Kopfzeile
- Kampf-Erkennung wie Questlog (Kill, Wipe, Pause, Zonenwechsel), Todeszähler pro Kampf
- Die letzten 10 Kämpfe (‹ ›), Ping in ms, GS/CP der Gruppe, Gruppensuche-Liste
- Alt+E: Einstellungen, Alt+V: ein-/ausblenden; Updates werden beim Start angeboten

Der Meter liest nur mit, was der Spielserver an den eigenen PC schickt. Er sendet nichts an das Spiel
und verändert nichts. Einzige Verbindung: beim Start die Update-Abfrage hier bei GitHub.

Kein offizielles Produkt; nicht mit NCSOFT oder Questlog verbunden. Skill-Namen, Boss-Liste und
Klassensymbole stammen von Questlog bzw. aus dem Spiel.
